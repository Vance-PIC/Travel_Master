# 🎒 第三章：行李準備與打包清單

> **[打包紀律]**：出發前 3 天開始對照勾選，確保所有死線備品（如護照、駕照譯本、兒童藥品）無一遺漏。

---

## 🗃️ 1. 核心證件與金融 (Essentials)
- [ ] **護照正本**（有效期限需大於 6 個月）。
- [ ] **身分證 / 健保卡**（國內線登機備用）。
- [ ] **日圓現鈔**（預算建議：每人每日 ¥5,000 ~ ¥10,000 基本備用金）。
- [ ] **海外高回饋信用卡**（至少準備 2 張，分開放置防盜防刷）。
- [ ] **Visit Japan Web 入境截圖**（強烈建議在台灣先截圖保存 QR Code，防機場網路卡關）。

## 📱 2. 電子設備與通訊 (Tech & Power)
- [ ] **智慧型手機與充電線**。
- [ ] **行動電源**（民航規定：必須隨身登機，且規格標示必須清晰，否則會被海關沒收）。
- [ ] **多孔 USB 充電頭**（日本與台灣插頭通用，免轉接，但大跨度飯店插座常不足，建議多孔頭）。
- [ ] **日本網卡 / Wi-Fi 分享器**（實體 SIM 卡、eSIM 或分享器）。

## 🍼 3. 親子專屬備品 (Kids Essentials - 核心亮點)
- [ ] **輕便摺疊推車 / 背巾**（大縱貫鐵道行軍必備，推車需符合新幹線與電車攜帶規範）。
- [ ] **便攜型兒童餐具 / 剪刀**（日本多數餐廳提供兒童椅，但自備餐具更衛生安全）。
- [ ] **兒童常備藥品**（退燒藥、感冒藥、止瀉藥、防蚊液，出發前請小兒科開立備用）。
- [ ] **便攜型濕紙巾 / 乾洗手**（親子行軍消耗量極大）。
- [ ] **安撫小點心 / 玩具**（新幹線大跨度移動時，安撫小孩的最終防線）。

## 💊 4. 個人藥品與盥洗 (Medical & Clothing)
- [ ] **個人常備藥**（暈車藥、慢性病藥物）。
- [ ] **換洗衣物**（根據天數準備，建議善用飯店的投幣式洗衣機，減少行李重量）。
- [ ] **好走的健走鞋 / 運動鞋**（鐵道縱貫日行萬步基本盤，嚴禁穿新鞋或磨腳鞋）。
- [ ] **折疊雨傘 / 輕便雨衣**（梅雨季或突發降雨防線）。
- [ ] **小垃圾袋數個**（日本街頭極難找到垃圾桶，帶著小孩時可隨時暫存垃圾）。

## ⚠️ 5. 日本出入境打包防雷守則 (Rules)
1. **腳架與自拍棒**：收合後高度**必須小於 60 公分**才能隨身登機，否則強制託運。
2. **隨身液體限制**：單一容器不得超過 100ml，且需裝入 1 公升以下之透明夾鏈袋內。
3. **新幹線特大行李預約**：行李箱三邊合計超過 160cm 且在 250cm 以內，搭乘東海道/山陽/九州新幹線時，必須提早預約「特大行李放置處附帶席」。
