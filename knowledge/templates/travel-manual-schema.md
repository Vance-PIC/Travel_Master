# Travel Manual Governance Schema (D2 Final Edition)

本文件根據 D1 Context 定義，為手冊治理之「規格」依據，作為 D4/D5 審計之依據。

## 1. 全域寫作原則
- **語言**: 100% 繁體中文，嚴禁簡體。
- **透明度**: 零省略原則（禁出現 `(略)`）。
- **環境**: 全章節標註「全館禁菸」或「禁菸車」。
- **語氣**: 溫馨、親切、自然之家庭親子導向語氣。

## 2. 模組化規格 (Module Specifications)

### Type A: 行程總覽與預算 (Chapter 1)
- **1.2 預算明細**: 
  - **細粒度**: 強制「一筆一行」。
  - **數據對齊**: 必須包含全天數之住宿、長途交通（飛機/租車）等核心移動預算。

### Type B: 每日詳細行程總覽 (Chapter 2)
- **通用必備**: 🗓️ 7 日行程總覽表（含天數、日期、主要行程地點、主要交通工具、當晚住宿）、💡 行程小提醒（全局經營原則）、📅 快速跳轉每日行程索引。

### Type C: 每日行程 (Day X)
- **通用必備**: 🏨 今日住宿、📍 今日主線、📍 今日行程表、💡 今日小提醒、🍴 今日美食地圖、🛍️ 今日購物攻略、🏟️ 推薦景點表。
- **導航與定位強化**: 
  - 所有美食、購物與景點名稱必須包含 Google Map 超連結。
  - 美食必須包含當天實際營業時間與 Tabelog 評分（無則留空），購物與景點必須包含營業時間/門票。
  - 表格必須包含交通位置並明確註明相對於當晚入住飯店的距離（例如 `🐾 離飯店步行 X 分鐘`）。
- **美食備案**: 每一餐別（早/午/晚/品）提供至少 **3 筆** 資料，以防客滿或未營業。
- **今日小提醒**: 針對當日行程提供至少 3 條實務防雷與親子溫馨建議。
