#### **💡 行程小提醒 (旅途中經營與執行原則)**
全家出遊期間，建議留意以下實務經營與執行原則：

1. **每天一個主景點**：D2 樂高、D4 東山、D5 科學館、D6 水族館。全行程以孩子體力與舒適度為核心，其他地點可以刪，不追求打卡數；遇午後高溫或體力下降隨時至室內商場或回飯店休息。
2. **交通保留彈性**：名古屋站轉青波線、熱田轉名港線等轉乘，現場跟著站內導引與即時路線走；文內分鐘是緩衝估算，不是 2027 固定班次。推車或大件行李優先搭乘無障礙電梯（如久屋大通 2A 出口電梯）。
3. **炎熱與感官負荷**：若排隊壓力較大，D2 先問園方 AAP 條件並安排避開聲光刺激的休息點；小紅卡是否適用日本票價減免以現場回覆為準。[LEGOLAND 協助服務](https://www.legoland.jp/resort-guide/service/guests-with-disabilities/)
4. **16:00 後收束**：不再新增高體力景點，只回飯店（可善用飯店大浴場與洗衣機）、吃晚餐或順路逛商場。D3 的夜景是可取消選項。
5. **2026/11 日本免稅新制（先含稅、機場海關確認後退稅）**：自 2026/11/1 起日本已全面改為「リファンド方式」，市區店家與百貨**已無當場免稅結帳**——結帳時先付含稅價並出示護照登錄免稅紀錄；D7 抵達中部國際機場 T1 時，**務必在星宇航空託運行李前**，先用機場免費 Wi-Fi 透過 Visit Japan Web 或海關 KIOSK 端末完成免稅確認再託運（僅出境後「管制區內免稅店」可直接免稅結帳）。
6. **出發前覆核提醒**：機票、餐廳訂位與 2027 年度各館營業日曆及票價，請於出發前 1–2 個月依官方最新公告再次確認。
