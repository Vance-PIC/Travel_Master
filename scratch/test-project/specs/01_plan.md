## 3. 詳細大綱與物理檢索依據
> **[零幻覺檢索]**：本章節內容將基於以下實體福岡大眾運輸規章與交通指南：
* **參考來源 1**：福岡市地下鐵官網（票價與票券規格：地鐵一日券售價 640 日圓）。
* **參考來源 2**：西鐵電車官網（天神至太宰府單程票價 420 日圓，西鐵太宰府散策套票資訊）。

### **實作大綱**：
1. **🛫 福岡機場至博多市區交通銜接**：
   - 方式 A：國際線搭乘接駁巴士（免費）至國內線航廈 ➔ 轉乘福岡市營地下鐵機場線至博多站（車程 5 分鐘，票價 260 日圓，標明地鐵博多站有電梯之改閘口與出口）。
   - 方式 B：國際線航廈直接搭乘「西鐵聯絡巴士」直達博多站（車程 15 分鐘，票價 310 日圓）。
2. **🎫 福岡市區大眾運輸票券攻略**：
   - **福岡地鐵一日券 (Subway 1-Day Pass)**：售價 640 日圓，當日搭乘地鐵 3 次以上即划算。
   - **交通 IC 卡 (SUGOCA / ICOCA / Suica)**：用於便利商店與地鐵單程，方便快速改閘。
3. **🎒 不自駕寄物與飯店行李寄託指引**：
   - 博多車站（JR Hakata City）1 樓與地下 1 樓寄物區分佈（優先推薦改閘口旁的大型置物櫃）。
   - 飯店寄放行李 SOP：抵達博多站後，先前往飯店辦理 Check-in / 寄放行李，再開始行程。
4. **🤝 神隊友溫馨提醒 (行前篇)**：
   - 攜帶大型行李（長寬高合計超過 160 公分）搭乘 JR 新幹線需預約行李席（若行程有涉及）。
   - 入境必備 Visit Japan Web 申報 QR Code 截圖。
