#### **💡 行程小提醒 **
全家暢遊熊本阿蘇期間，建議留意以下實務經營原則：

# 🎒 第三章：行李準備與打包清單





> **打包提醒**：出發前 3 天開始對照勾選，確保所有關鍵必備物品（如護照、台灣駕照正本與日文譯本、兒童藥品）無一遺漏。

---

## 🧳 0. 行李配置與回程叫車
- [ ] **2 個 28 吋行李箱＋2 個登機箱＋4 個背包**；出發前確認航空公司每件行李額度與總重量。
- [ ] **折疊購物袋／環保袋**（D5 道の駅阿蘇、D6 AEON 與 DAISO 採買使用）。
- [ ] **可折疊保冷袋**（車上飲料、D5 乳製品與短程冷藏食品使用）。
- [ ] **行李秤**（沒有就於 D6 AEON／DAISO 補買；D6 晚上完成最終配重）。
- [ ] **D7 叫車容量**：首選 Jumbo Taxi；兩台普通計程車僅作自行叫車備案。

## 🚗 1. 日本自駕取車關鍵證件 (Must Have for Self-Drive)
- [ ] **護照正本**。
- [ ] **台灣駕照正本**（**極重要**！日本監理所規定必須同時出示台灣駕照原本與日文譯本，僅帶譯本無法取車）。
- [ ] **日文翻譯本**（需在台灣監理所或日本 JAF 辦理，出發前確認在效期內）。

## 🗃️ 2. 核心證件與金融 (Essentials)
- [ ] **身分證 / 健保卡**（國內段機場備用）。
- [ ] **日圓現鈔**（自駕備用金，日本部分加油站或鄉下景點僅收現金，建議準備充足）。
- [ ] **海外高回饋信用卡**（至少準備 2 張，取車時需刷卡支付押金/租金）。
- [ ] **Visit Japan Web 入境截圖**（在台灣先截圖保存 QR Code，防熊本機場網路卡關）。

## 📱 3. 電子設備與車載配件 (Tech & Car Accessories)
- [ ] **智慧型手機與充電線**。
- [ ] **行動電源**（必須隨身登機，規格標示需清晰）。
- [ ] **車用 USB 充電器 / 車充線**（自駕長時間導航手機充電必備）。
- [ ] **車用手機支架**（租車公司可能不提供，建議自備以利導航）。
- [ ] **多孔 USB 充電頭**（日本與台灣插頭通用）。
- [ ] **日本網卡 / Wi-Fi 分享器**（自駕山區導航，網路訊號極為重要）。

## 🍼 4. 親子與自駕專屬備品 (Kids & Drive Essentials - 核心亮點)
- [ ] **重要文件收納袋／隨身背包**（放護照、台灣駕照、日文譯本、訂房／租車資料及 Greenland 優待證明正本；本次不另帶 Kånken 包）。
- [ ] **安全汽座確認**（取車時確認租車公司已安裝符合兒童年齡的汽座）。
- [ ] **便攜型兒童餐具 / 剪刀**（防磨損與衛生，自駕遊玩隨時可用）。
- [ ] **兒童常備藥品**（退燒、止瀉、防蚊液，自駕鄉間看診不易，必備常備藥）。
- [ ] **便攜型濕紙巾 / 乾洗手**（車上隨時清潔用）。
- [ ] **車上娛樂道具**（安撫音樂、小玩具，防塞車或長途行車小孩哭鬧）。
- [ ] **遮陽帽、防曬乳、涼感毛巾與補水用品**（Greenland 採陸上版，不攜帶整套水樂園裝備）。

## 💊 5. 個人藥品與盥洗 (Medical & Clothing)
- [ ] **個人常備藥**（暈車藥、慢性病藥物，自駕山路如阿蘇山易暈車，暈車藥必備）。
- [ ] **換洗衣物**（根據天數準備，建議善用飯店的投幣式洗衣機，減少行李箱佔用空間）。
- [ ] **好走的健走鞋 / 運動鞋**（Greenland 全日遊、阿蘇健行必備）。
- [ ] **折疊雨傘 / 輕便雨衣**。
- [ ] **小垃圾袋數個**（車上收集垃圾用，日本隨處丟垃圾極不便）。

## ⚠️ 6. 日本租車自駕防雷守則 (Rules)
1. **取車檢查**：與店員確認車身外觀擦傷，並當場拍照留底；確認油箱是否已加滿。
2. **保險等級**：強烈建議保足 NOC (Non-Operation Charge) 營業損失賠償險，防突發擦撞。
3. **導航設定**：優先使用 MapCode 或電話號碼設定車載導航，Google Map 做為輔助導航。
4. **加油種類**：日本租車一般加 **「レギュラー」(Regular/紅槍)**，切勿加錯柴油或高辛烷值汽油。
