# 🎒 第三章：行李準備與打包清單

[🏠 返回總目錄](./00_Index.md)

[⬅️ 上一頁 (Day 7：常滑返台)](./02.07_Day7_常滑返台.md)

> 出發前 3 天開始對照這份清單打包，把最重要的護照、小紅卡、行動電源與兒童藥品先收進隨身包，出發當天就不會手忙腳亂。

---

## 🗃️ 1. 核心證件與金融
- [ ] **護照正本（4 人）**：出發前先檢查有效期限須大於 6 個月；D1 進機場辦孩子的「小兒用 manaca」也會用到。
- [ ] **小紅卡（正本與英文譯本）**：入園樂高樂園洽詢 AAP 友善通關，以及動物園／水族館詢問現場優惠時使用。
- [ ] **外圍停車與接駁資訊**：大園第三停車場預約確認、回國聯絡電話與接駁位置。
- [ ] **機票與訂房資料**：星宇航空電子機票、LiVEMAX PREMIUM 名古屋丸之內訂房確認單（Agoda 訂單 `1770065317`）。
- [ ] **日圓現鈔與海外信用卡**：多數商場與交通可刷卡或用手機 IC 卡，現金主要備著買小兒 manaca（每張 ¥2,000）、扭蛋與商店街小吃；建議帶 2 張高回饋信用卡分開收好。
- [ ] **手機交通卡與入境截圖**：大人先在 Apple Wallet 綁好 Suica／ICOCA 並儲值；Visit Japan Web 的入境 QR Code 先截圖存在手機相簿，免得機場網路卡關。

## 📱 2. 電子設備與通訊
- [ ] **智慧型手機與充電線**：記得多帶一條備用線。
- [ ] **行動電源**：**一定要放隨身行李帶上飛機**，禁止託運；機身容量與規格標示要清楚。
- [ ] **多孔 USB 充電頭**：日本雙孔插座與台灣相同（免帶轉接頭），帶多孔頭一次充手機和行動電源最方便。
- [ ] **日本網卡 / eSIM**：出發前先看好開通說明，下飛機就能直接連線。

## 🎒 3. 親子出遊與 7 月避暑裝備（10 歲／8 歲專屬）
- [ ] **水壺（每人 1 個）**：7 月樂高樂園與東山動物園天氣炎熱，每天出門裝滿水隨時補充水分。
- [ ] **防曬乳、遮陽帽與太陽眼鏡**：白天戶外園區必備；防曬噴霧請放托運箱。
- [ ] **涼感濕紙巾 / 隨身小風扇**：排隊或戶外移動時降溫很有用（含鋰電池的小風扇請放隨身行李）。
- [ ] **兒童常備藥品**：退燒藥、感冒藥、腸胃藥、暈車藥、OK 繃與防蚊貼片，出發前請小兒科開立備用。
- [ ] **便攜型濕紙巾與小垃圾袋數個**：日本街頭垃圾桶很少，買小點心邊走邊吃時方便暫存垃圾。
- [ ] **折疊晴雨傘或輕便雨衣**：7 月午後雷陣雨備用，在樂高樂園玩水上射擊設施時也能派上用場。

## 👕 4. 衣物與日常用品
- [ ] **換洗衣物 3–4 套即可**：飯店房內就有洗衣機、館內 3F 也有投幣式洗烘衣機，不用帶滿 7 天衣服，留出空間裝戰利品。
- [ ] **好走、已穿習慣的運動鞋**：每天步行都在一萬步以上，不要穿全新容易磨腳的鞋。
- [ ] **輕薄防曬外套或長袖薄衫**：室外防曬，進科學館、水族館與百貨冷氣房時又能保暖。
- [ ] **個人常備藥與盥洗保養分裝**：隱形眼鏡、個人藥品與慣用保養品（大瓶裝或新買的液體回程記得放托運箱）。

## ⚠️ 5. 出入境打包與免稅注意事項
1. **行動電源與鋰電池**：一律放隨身行李登機，不可放托運箱。
2. **隨身液體限制**：單一容器不得超過 100ml，並須裝進 1 公升以下透明夾鏈袋；超過 100ml 的防曬、保養品或飲料請放托運箱。
3. **自拍棒與腳架**：收合後長度須小於 60 公分才能隨身登機，超過請放托運箱。
4. **回程退稅順序別弄錯（2026/11 起新制）**：日本商場結帳一律先付含稅價並刷護照登錄紀錄，**回程在中部國際機場務必先完成海關退稅確認（KIOSK 或 Visit Japan Web），才能去星宇航空櫃檯託運行李**；需託運的液體免稅品等海關確認完再裝箱託運。
