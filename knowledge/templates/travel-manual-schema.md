# Travel Manual Governance Schema (D2 Final Edition)

本文件根據 D1 Context 定義，為手冊治理之「憲法級」規格，作為 D4/D5 審計之依據。

## 1. 全域寫作原則
- **語言**: 100% 繁體中文，嚴禁簡體。
- **透明度**: 零省略原則（禁出現 `(略)`）。
- **環境**: 全章節標註「全館禁菸」或「禁菸車」。

## 2. 模組化規格 (Module Specifications)

### Type A: 核心戰報 (Chapter 1)
- **1.2 預算明細**: 
  - **細粒度**: 強制「一筆一行」。
  - **數據對齊**: 必須包含全天數之住宿、長途交通（新幹線/飛機/租車）等核心大跨度移動預算。

### Type B: 作戰中心 (Chapter 2)
- **通用必備**: 📋 縱貫行軍黃金守則（看盤/退稅/國內線/演唱會等死線提醒）、📅 快速跳轉每日任務索引。

### Type C: 每日作戰 (Day X)
- **通用必備**: 🏨 今日住宿、📍 今日行程表、🍴 今日美食地圖、🛍️ 今日購物攻略、🏟️ 推薦景點表、🤝 神隊友提醒。
- **導航與定位強化**: 
  - 所有美食、購物與景點名稱必須包含 Google Map 超連結。
  - 美食必須包含當天實際營業時間與 Tabelog 評分（無則留空），購物與景點必須包含營業時間/門票。
  - 表格必須包含交通位置並明確註明相對於當晚入住飯店的距離（例如 `🐾 離飯店步行 X 分鐘`）。
- **美食定量**: 每一餐別（早/午/晚/品）提供至少 **3 筆** 資料，以防客滿或未營業。
- **神隊友提醒**: 針對當日行程提供至少 3 條實務防雷與防空建議。

## 3. 命名與分割規則
- 目標路徑: `src/`
- 格式: `[ID]_[Day/Chapter]_[標題].md`
