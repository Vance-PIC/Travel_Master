# GitHub Pages 公開價格儀表板設計

## 目的與範圍

為現有的名古屋機票與飯店監控建立公開、唯讀的價格儀表板。公開頁沿用 `travel/nagoya/nagoya_travel_master_dashboard.html` 的視覺風格及機票、飯店比較區，但移除逐日行程與家庭私人資訊。公開頁是獨立產物；現有完整儀表板及監控資料繼續保留於私人 `Vance-PIC/Travel_Master`。

公開頁可以顯示航線、旅行日期、航空公司、航班號、飯店名稱及已觀測價格。不得公開逐日行程、旅客人數與年齡、已訂房狀態或訂房基準、家庭預算、私人備註、API 原始回應、金鑰或監控設定。任何知道網址的人都能瀏覽公開頁及其靜態檔案。

## 採用方案

從私人儲存庫的監控快照，依明確的欄位白名單產生小型靜態網站；只把產出的 `_site/index.html` 同步至獨立公開儲存庫 `Vance-PIC/Travel_Master_Prices`（暫定名稱）。GitHub Pages 從公開儲存庫的 `main` 根目錄發布。私人 `Travel_Master` 不改為公開，不直接發布現有完整儀表板或整個 `travel/nagoya` 目錄。使用需驗證的 Cloud Run 儀表板雖能保護私人資訊，但會增加服務維護；直接發布現有 HTML 則會洩漏私人資訊及未獲資料支持的價格宣稱。公開價格頁無須採用這兩種方式。

## 資料與畫面

- 機票資料來源為 `travel/nagoya/flights/latest.json`。按 `displayed_price_twd` 由低至高顯示最多五筆有效的完整去回程組合，包含航空公司、去回程航班號與時間、API 顯示價格、價格範圍及該組合自己的 `checked_at`。原始快照與完整歷史維持不變；市場候選航班不得冒充完整去回程組合。
- 除非某組合具備當次有效的 Booking Options 驗證、`price_scope=family_total` 及 `family_total_twd`，否則價格只能標為「API 顯示價格，未驗證為家庭總價」。不得乘上旅客人數，也不得推測行李、票價條件、省下金額或購票建議。未驗證的價格範圍與行李明確標為未知。
- 飯店資料來源為可取得的 `travel/nagoya/hotels/*/latest.json`。顯示飯店名稱、住宿日期、觀測金額與原幣別、資料來源、各報價的觀測時間，以及已記錄的驗證或比較狀態。沒有可靠匯率證據時不得自行換匯；若某監控沒有有效現價，顯示「無可用報價」或「資料過期」，不可捏造價格。
- 狀態區簡要標示各資料來源的最新觀測時間，以及過期、缺漏或未驗證狀態。若報價距頁面產生時間超過 48 小時，即標示「資料過期」；仍可保留最後有效報價供參考。不得以網頁產生時間冒充報價觀測時間。
- 沿用現有儀表板的基本風格、機票／飯店分區與比較表。移除八日行程規劃、家庭資訊、已訂房敘述、寫死的購票管道價格及未驗證的權益宣稱。

## 更新與發布

現有每日機票與飯店監控仍是唯一排程呼叫查價 API 的流程；此次不增加搜尋、不新增監控排程，也不呼叫 SerpApi、Ignav 或 SearchAPI。發布流程在任一監控流程完成後，從私人儲存庫預設分支的最新快照建立公開頁。另提供手動執行及相關頁面程式變更後發布，以便首次上線與維護。監控流程的提交使用 `GITHUB_TOKEN`，因此更新不能只依賴 `push` 事件。

發布流程檢出私人儲存庫預設分支，只讀取本地檔案，產生專用的公開目錄，再只暫存並推送 `index.html` 到公開儲存庫。跨儲存庫推送使用私人儲存庫 Actions secret `PUBLIC_PAGES_TOKEN`，其 fine-grained PAT 僅能存取公開目標儲存庫且具 Contents read/write；缺少 secret 時流程應在修改公開儲存庫前明確失敗。權杖值不得出現在 URL、程式碼或日誌。私人儲存庫的 `GITHUB_TOKEN` 僅需 contents read。監控失敗時不得抹除最後有效價格；頁面需顯示原始觀測時間。發布失敗時，保留前次已發布頁面並讓 Actions 顯示失敗。不得使用不受信任分支的程式碼或 artifact 產生公開頁。

## 驗證與完成條件

1. 用本地測試資料驗證排序、原幣別、未知與已驗證家庭總價的標示、缺少快照的處理，以及 HTML 跳脫。
2. 檢查發布產物不含旅客人數與年齡、家庭預算、逐日行程、已訂房基準、原始 JSON 或金鑰；產物只含白名單欄位。
3. 確認發布流程不帶查價憑證、不呼叫外部機票／飯店 API，僅複製 `index.html`，並檢查觸發條件與權限。
4. 經該次發布核准後建立公開儲存庫並將 Pages 設為 `main` / root；手動執行發布後，核對公開儲存庫內容、網址、有效價格、各筆資料時間與私人區塊未公開。

Cloud Run MCP 部署及其密鑰不在此次變更範圍內。既有監控政策與正式排程不變。
