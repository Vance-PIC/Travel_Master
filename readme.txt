========================================================================
2026 熊本阿蘇 7 日親子自駕：終極作戰手冊 (旅行大師 Edition) - 專案指引
========================================================================

本專案致力於打造最適合親子自駕的熊本阿蘇作戰手冊，嚴格遵循 Document Governance 
(D1~D5) 治理協議與 Git-Flow 協作流程。

------------------------------------------------------------------------
📂 目錄結構說明
------------------------------------------------------------------------
- src/          : 各章節的來源 Markdown 檔案（唯一真理，所有內容修改以此為準）。
- conductor/    : 專案治理計畫、WBS 看板與進度報告。
  - doc-tracks.md     : WBS 與 Track 狀態註冊表。
  - progress_report.md: 進度摘要報告。
- scripts/      : 品質稽核與合併發布腳本。
  - audit-src.ps1    : 執行單一或全域章節的格式與內容審計。
  - merge-doc.ps1    : 將 src/ 下的所有章節物理合併為最終發布檔。
  - sync-tracks.ps1  : 同步並更新看板狀態。
- knowledge/    : 歷史版本、規格參考與寫作範本。
- specs/        : 各階段的設計規格書與任務計畫。

------------------------------------------------------------------------
🛠️ 常用維護指令 (請於 Windows PowerShell 執行)
------------------------------------------------------------------------
1. 執行本地原始碼審計：
   pwsh -NoProfile -Command "chcp 65001; ./scripts/audit-src.ps1"

2. 執行全域發布與文檔物理合併：
   pwsh -NoProfile -Command "chcp 65001; ./scripts/merge-doc.ps1"

3. 同步進度看板：
   pwsh -NoProfile -Command "chcp 65001; ./scripts/sync-tracks.ps1 -Status DONE"

------------------------------------------------------------------------
⚠️ 協作紀律提醒
------------------------------------------------------------------------
1. 修改前請務必確認 doc-tracks.md 對應的階段。
2. 進行內容撰寫時，必須對齊 knowledge/templates/ 下的規範範本，嚴禁省略。
3. 發布前必須確保 audit-src.ps1 執行結果為全綠 [OK]。
