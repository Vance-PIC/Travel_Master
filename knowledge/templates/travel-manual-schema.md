# Travel Manual Governance Schema (D2 Final Edition)

本文件根據 D1 Context 定義，為手冊治理之「憲法級」規格，作為 D4/D5 審計之依據。

## 1. 全域寫作原則
- **語言**: 100% 繁體中文，嚴禁簡體。
- **透明度**: 零省略原則（禁出現 `(略)`）。
- **環境**: 全章節標註「全館禁菸」或「禁菸車」。

## 2. 模組化規格 (Module Specifications)

### Type A: 核心戰報 (Chapter 1)
- **1.2 預算明細**: 
  - **細粒度**: 強制「一筆一行」。
  - **數據對齊**: 必須包含 OMO5 三日明細 (¥19.5k/18.6k/18.6k) 與阿蘇農場明細 (¥78,080)。
  - **租車**: 必須列出基本費與汽座費用。

### Type B: 每日作戰 (Day X)
- **通用必備**: 🏨 住宿、📍 行程表、🍴 美食地圖、🛍️ 購物攻略、🏟️ 推薦景點、💡 神隊友提醒。
- **導航強化 (D3 ~ D6)**: 景點與餐廳表格必須包含 `MapCode` 或 `電話` 欄位。
- **無障礙標註**: 景點表必須包含 `身障優惠` 欄位。
- **美食定量**: 每餐別（早/午/晚/宵/小吃）提供 **3-5 筆** 資料。
- **神隊友提醒**: 針對親子團大人提供至少 3 條實務建議。

## 3. 命名與分割規則
- 目標路徑: `src/`
- 格式: `[ID]_[Day/Chapter]_[標題].md`
