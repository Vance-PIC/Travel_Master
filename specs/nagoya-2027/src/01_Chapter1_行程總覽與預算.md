- 每 60–90 分鐘找座位、喝水、上廁所；戶外日的 12:00–14:00 優先移到室內。
- D4 東山遇酷暑或大雨，改室內科學館；但科學館固定週一及第 3 個週五休館，仍須看 2027 年日曆。[科學館官方](https://www.ncsm.city.nagoya.jp/visit/visitors_guide/admission.html)

#### **💡 出發前小提醒 (行前行政與證件)**
1. **證件與證明準備**：出發前確認全家護照有效期限（>6 個月）、攜帶**弟弟台灣身心障礙證明正本與英文譯本**（供各場館詢問協助／優惠用），並預先完成 Visit Japan Web 截圖保存 QR Code 與網卡／eSIM 設定。
2. **機場交通與接駁**：出發前預約桃園機場外圍「大園第三停車場」停車位與接駁時段（建議起飛前 3 小時以上抵達停車場）；抵達中部國際機場後，預先確認名鐵 μSKY／一般特急購票方式與手機交通 IC 卡（Suica / ICOCA / manaca）餘額。
3. **海外支付與備用金**：準備至少 2 張海外高回饋信用卡（分開存放），並預留適量日圓現鈔作為寄物櫃、小額餐飲、門票與傳統店家的備用金。
