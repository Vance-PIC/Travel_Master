# 📝 章節實作計畫 (WP-03) - Day 2：西鐵太宰府散策與天神購物

## 1. 撰寫目標與背景
* **單元名稱**：Day 2：西鐵電車太宰府天滿宮參拜、天神地下街與百貨購物、天神人氣牛腸鍋美食
* **讀者畫像與痛點**：不自駕夫妻。早上搭乘西鐵前往太宰府，需要明確的轉乘（西鐵二日市站）或直達車（觀光電車「旅人號」）指引。下午在龐大的天神購物商圈（福岡 PARCO、岩田屋、天神地下街）移動時，需提供一條不重複、最省體力的室內串聯動線。晚餐熱門漢堡排店（極味屋）排隊耗時且油煙重，需給予排隊緩衝方案與高質感禁菸餐廳備案。
* **核心原則對齊**：
  * **步行動線最優化**：利用天神地下街的地下通道與電梯，雨天或烈日下皆能全室內移動。單次步行嚴禁超過 15 分鐘。
  * **轉乘清晰度**：精確標示「西鐵福岡(天神)站」至「太宰府站」的電車搭乘細節，避免坐錯慢車。
  * **美食定量與防雷**：精選 3-5 筆代表性餐廳，特別列出「極味屋排隊避油煙指南」與「全店禁菸的牛腸鍋餐廳」。
  * **嚴禁自駕**：不出現任何自駕、車程、加油或 MapCode 資訊。

   - 13:30 - 14:10：回程：搭西鐵電車太宰府線至二日市站 ➔ 轉乘大牟田線急行返抵西鐵天神站。
   - 14:10 - 18:00：天神商圈購物（福岡 PARCO ➔ 天神地下街 ➔ 岩田屋百貨，標記全程免日曬雨淋之地下通道）。
   - 18:00 - 20:30：晚餐：博多牛腸鍋おおやま 天神店（全店禁菸，品嚐博多經典白味噌湯頭）。
